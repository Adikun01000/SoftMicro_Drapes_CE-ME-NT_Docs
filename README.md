## Installation Guide

### Prerequisites

Before installation, ensure that your system meets the following requirements:

- Operating System: Windows, macOS, or Linux
- Git: Installed on your system
- Basic command-line knowledge

### Installation Steps

1. **Download the Latest Release**  
   Visit the [Releases section](https://github.com/Adikun01000/SoftMicro_Drapes_CE-ME-NT_Docs/releases) to download the latest version.

2. **Run the Installer**  
   Follow the instructions provided in the installer to complete the installation process.

3. **Verify Installation**  
   To verify that SoftMicro Drapes is installed correctly, run the following command in your terminal:
   ```bash
   drapes --version
   ```

## Usage Instructions

Once installed, you can start using SoftMicro Drapes. Here are some basic commands to get you started:

### Launching the Application

To launch the application, use the following command:
```bash
drapes start
```

### Accessing Help

For help with commands and features, run:
```bash
drapes help
```

### Common Commands

- **Open a File**: 
   ```bash
   drapes open <filename>
   ```
- **Close the Application**: 
   ```bash
   drapes exit
   ```
